# 首个可演示主流程

## 准备

在已激活 `sports_stadium` 环境后执行：

```powershell
python manage.py migrate
python manage.py seed_demo
python manage.py runserver
```

访问：`http://127.0.0.1:8000/`

## 主流程脚本

### 1. 普通用户预约

1. 使用普通用户登录。
2. 进入“场馆列表”。
3. 打开“演示综合体育馆”。
4. 查看 A1 篮球场和 2026-05-08 09:00-10:00 时段。
5. 点击“预约”。
6. 进入“我的预约”，确认状态为待审核。

### 2. 场馆管理员审核预约

1. 退出普通用户。
2. 使用场馆管理员登录。
3. 进入“预约审核”。
4. 查看普通用户提交的待审核预约。
5. 点击“通过”或“拒绝”。
6. 再切回普通用户查看“我的预约”，确认状态变化。

### 3. 评论展示与审核

1. 普通用户进入“演示综合体育馆”。
2. 已通过评论会直接展示。
3. 提交一条新评论，系统提示等待审核。
4. 使用系统管理员登录。
5. 进入“评论审核”，通过或拒绝待审核评论。
6. 回到场馆详情页确认只有已通过评论展示。

### 4. 系统管理员后台节点

1. 使用系统管理员登录。
2. 进入“场馆审核”，处理待审核场馆。
3. 进入“用户管理”，搜索手机号或昵称。
4. 进入“评论审核”，处理待审核评论。

## 预期演示重点

- 三类角色入口清晰。
- 普通用户不能管理场馆或审核预约。
- 场馆管理员只能审核自己场馆下的预约。
- 系统管理员负责平台级审核和用户管理。
- 已取消或未通过内容不会占用主流程展示位置。
